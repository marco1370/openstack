# S3 / Object Storage (RADOS Gateway)

The `ceph-rgw` container exposes an S3-compatible endpoint on port **7480**.  
Any S3 client works: AWS CLI, `s3cmd`, `rclone`, `mc`, `boto3`, etc.

---

## Connection details

| Setting       | Value                    |
|---------------|--------------------------|
| Endpoint URL  | `http://localhost:7480`  |
| Region        | `us-east-1` (any value)  |
| Path-style    | Required (no virtual-host)|

---

## AWS CLI setup

### Option A — Environment variables (per session)

```bash
export AWS_ACCESS_KEY_ID=testaccess
export AWS_SECRET_ACCESS_KEY=testsecret
export AWS_DEFAULT_REGION=us-east-1
export S3=http://localhost:7480      # convenience alias

# Test connectivity
aws --endpoint-url $S3 s3 ls
```

### Option B — Named profile (persistent)

```bash
aws configure --profile ceph
# AWS Access Key ID:     testaccess
# AWS Secret Access Key: testsecret
# Default region name:   us-east-1
# Default output format: json

# Use the profile
aws --profile ceph --endpoint-url http://localhost:7480 s3 ls
```

## Bucket operations

```bash
ENDPOINT=http://localhost:7480

# Create a bucket
aws --endpoint-url $ENDPOINT s3 mb s3://my-bucket

# List all buckets
aws --endpoint-url $ENDPOINT s3 ls

# Delete an empty bucket
aws --endpoint-url $ENDPOINT s3 rb s3://my-bucket

# Delete a bucket and all its contents
aws --endpoint-url $ENDPOINT s3 rb s3://my-bucket --force
```

## Object operations

### Upload

```bash
# Upload a single file
aws --endpoint-url $ENDPOINT s3 cp ./file.txt s3://my-bucket/

# Upload with a custom key (path inside bucket)
aws --endpoint-url $ENDPOINT s3 cp ./file.txt s3://my-bucket/data/archive/file.txt

# Recursive upload of a directory
aws --endpoint-url $ENDPOINT s3 cp ./mydir/ s3://my-bucket/mydir/ --recursive

# Sync a local directory to a bucket (only uploads changed/new files)
aws --endpoint-url $ENDPOINT s3 sync ./mydir/ s3://my-bucket/mydir/
```

### Download

```bash
# Download a single file
aws --endpoint-url $ENDPOINT s3 cp s3://my-bucket/file.txt ./file-copy.txt

# Download an entire prefix
aws --endpoint-url $ENDPOINT s3 cp s3://my-bucket/data/ ./data-local/ --recursive

# Sync bucket to local directory
aws --endpoint-url $ENDPOINT s3 sync s3://my-bucket/ ./local-backup/
```

### List

```bash
# List objects in a bucket
aws --endpoint-url $ENDPOINT s3 ls s3://my-bucket/

# List recursively (shows sizes)
aws --endpoint-url $ENDPOINT s3 ls s3://my-bucket/ --recursive --human-readable

# List with a prefix filter
aws --endpoint-url $ENDPOINT s3 ls s3://my-bucket/data/
```

### Delete

```bash
# Delete a single object
aws --endpoint-url $ENDPOINT s3 rm s3://my-bucket/file.txt

# Delete all objects under a prefix
aws --endpoint-url $ENDPOINT s3 rm s3://my-bucket/data/ --recursive

# Delete everything in a bucket (does not delete the bucket itself)
aws --endpoint-url $ENDPOINT s3 rm s3://my-bucket/ --recursive
```

### Presigned URLs

```bash
# Generate a presigned GET URL valid for 1 hour
aws --endpoint-url $ENDPOINT s3 presign s3://my-bucket/file.txt --expires-in 3600
```

## Object metadata

```bash
# Inspect an object's metadata
aws --endpoint-url $ENDPOINT s3api head-object \
  --bucket my-bucket --key file.txt

# Upload with custom metadata
aws --endpoint-url $ENDPOINT s3 cp ./file.txt s3://my-bucket/file.txt \
  --metadata "author=alice,project=demo"

# Upload with a specific content-type
aws --endpoint-url $ENDPOINT s3 cp ./data.json s3://my-bucket/data.json \
  --content-type application/json
```

## User management (radosgw-admin)

All `radosgw-admin` commands run inside the `ceph-rgw` container.

### Create a user

```bash
docker exec ceph-rgw radosgw-admin user create \
  --uid=alice \
  --display-name="Alice Smith" \
  --email=alice@example.com \
  --access-key=alicekey \
  --secret=alicesecret
```

Output includes the full user record with keys and quota settings.

### List all users

```bash
docker exec ceph-rgw radosgw-admin user list
```

### Show a user

```bash
docker exec ceph-rgw radosgw-admin user info --uid=alice
```

### Modify a user

```bash
# Change display name
docker exec ceph-rgw radosgw-admin user modify \
  --uid=alice --display-name="Alice J. Smith"

# Suspend (disable) a user
docker exec ceph-rgw radosgw-admin user suspend --uid=alice

# Re-enable
docker exec ceph-rgw radosgw-admin user enable --uid=alice
```

### Add or rotate access keys

```bash
# Add a new key pair (auto-generated)
docker exec ceph-rgw radosgw-admin key create \
  --uid=alice --key-type=s3

# Add a specific key pair
docker exec ceph-rgw radosgw-admin key create \
  --uid=alice --key-type=s3 \
  --access-key=alice2key --secret=alice2secret

# Remove a key pair
docker exec ceph-rgw radosgw-admin key rm \
  --uid=alice --key-type=s3 --access-key=alice2key
```

### Set quotas

```bash
# Per-user quota: max 10 GiB, max 100 000 objects
docker exec ceph-rgw radosgw-admin quota set \
  --uid=alice --quota-scope=user \
  --max-size=10G --max-objects=100000

docker exec ceph-rgw radosgw-admin quota enable \
  --uid=alice --quota-scope=user

# Check quota usage
docker exec ceph-rgw radosgw-admin user stats --uid=alice
```

### Delete a user

```bash
# Delete user only (keeps their buckets and objects)
docker exec ceph-rgw radosgw-admin user rm --uid=alice

# Delete user AND all their data
docker exec ceph-rgw radosgw-admin user rm --uid=alice --purge-data
```

## Bucket management (radosgw-admin)

```bash
# List all buckets across all users
docker exec ceph-rgw radosgw-admin bucket list

# Show bucket stats
docker exec ceph-rgw radosgw-admin bucket stats --bucket=my-bucket

# Link a bucket to a different user
docker exec ceph-rgw radosgw-admin bucket link \
  --bucket=my-bucket --uid=bob

# Remove a bucket (must be empty)
docker exec ceph-rgw radosgw-admin bucket rm --bucket=my-bucket

# Remove a bucket and all its objects
docker exec ceph-rgw radosgw-admin bucket rm --bucket=my-bucket --purge-objects
```

## Multipart uploads

```bash
# List in-progress multipart uploads
docker exec ceph-rgw radosgw-admin reshard status --bucket=my-bucket 2>/dev/null || true

# Abort stale multipart uploads via AWS CLI
aws --endpoint-url $ENDPOINT s3api list-multipart-uploads \
  --bucket my-bucket

aws --endpoint-url $ENDPOINT s3api abort-multipart-upload \
  --bucket my-bucket \
  --key large-file.bin \
  --upload-id <UploadId>
```

## Using with Python (boto3)

```python
import boto3

s3 = boto3.client(
    "s3",
    endpoint_url="http://localhost:7480",
    aws_access_key_id="testaccess",
    aws_secret_access_key="testsecret",
    region_name="us-east-1",
)

# Create bucket
s3.create_bucket(Bucket="my-bucket")

# Upload
s3.upload_file("./file.txt", "my-bucket", "file.txt")

# Download
s3.download_file("my-bucket", "file.txt", "./file-copy.txt")

# List
resp = s3.list_objects_v2(Bucket="my-bucket")
for obj in resp.get("Contents", []):
    print(obj["Key"], obj["Size"])

# Delete
s3.delete_object(Bucket="my-bucket", Key="file.txt")
```

## RGW admin API

The RGW exposes an HTTP admin API at `/admin/`:

```bash
# Get admin credentials (uses the same access/secret as the admin user)
ADMIN_ACCESS=testaccess
ADMIN_SECRET=testsecret

# Usage stats (requires admin caps)
docker exec ceph-rgw radosgw-admin caps add \
  --uid=testuser --caps="usage=read,write"

curl "http://localhost:7480/admin/usage?uid=testuser" \
  --aws-sigv4 "aws:amz:us-east-1:s3" \
  --user "${ADMIN_ACCESS}:${ADMIN_SECRET}"
```
